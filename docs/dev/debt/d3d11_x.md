## Silent stubs

  Closes when: its arguments are known and it presents.

## Unknown function info

- `D3D11XCreateDeviceX` takes a 64-byte parameter block (first words `0x20012`, `0x2800000`) that is logged, not decoded. The device is created like `D3D11CreateDevice`: hardware, feature level 11.1 or 11.0.
  Title IDs: 1738CA2A
- Fast-table entries at +0x418, +0x430, +0x460, +0x470, +0x4F0, +0x4F8, +0x530 and +0x568 are forwarded as the PC method of the same slot; their argument encoding is not verified. `G6SHIM_TRACE=1` logs their first calls.
- Fast-table +0x420 takes a third argument (observed `0x76B40`) that is ignored. Fast-table +0x478 takes an index size where 0 is taken as 16-bit indices.
- Texture misc flags `0x20000` and `0x40000` mean tile pool and tiled resource on a PC and something else on the console. They are dropped with every flag from `0x10000` up.
  Title IDs: 3DD7389B
- Device vtable slots 64 and 85 are called and answered by probes (`E_NOTIMPL`).
  Title IDs: 34BA1DE0, 3DD7389B
- Console resource and view vtable slots 7 and 8, and resource slot 12, are probes.

## Functional

- MSAA is forced to one sample: every 2D texture is created single-sampled and multisampled view dimensions become plain ones.
  Closes when: multisampled targets are kept and read through views the PC accepts.
  Title IDs: 3DD7389B
- `ResolveSubresource` on a single-sampled source is done as `CopySubresourceRegion`.
- Renderer gaps: context fields +0x8A8, +0xAE8, +0xAF0, +0xAF8, +0xB08 and +0x9F0 (index buffer: is32, buffer, address) are unknown; placement vertex data is uploaded only when bound, not when the game writes it later; constant buffers addressed by GPU address are not handled.
  Closes when: the title draws its first frame correctly.
  Title IDs: 1738CA2A
- Constant buffers bound inside game memory are copied as a 4096-byte window on every bind.
- Vertex data uploaded from placement memory is capped at 1 MiB per bind.
- Topology types 5 (triangle fan) and 14 to 28 have no PC equivalent; draws keep the previous topology.
- Captured back buffers stay black although the title issues 31 draws per frame.
  Closes when: a captured frame shows the loading screen.
  Title IDs: 3DD7389B
