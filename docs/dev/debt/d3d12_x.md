## Unknown function info

- `D3D12XboxCreateDevice` logs its parameter block without decoding it beyond the version, and ignores the console adapter argument.
  Title IDs: 1738CA2A
- `CreateCommandQueueX` ignores the flags, engine and queue index; DMA queues become PC copy queues.
  Title IDs: 1738CA2A
- Descriptor heap `GetDesc` (slot 8) is taken to return through a hidden pointer passed before the heap; no title has called it yet.
- Device `GetCustomHeapProperties` (slot 26) and `GetAdapterLuid` (slot 31) are taken to return the console way; no title has called them yet. `GetResourceAllocationInfo` (slot 25) is observed.
  Title IDs: 1738CA2A
- Descriptor heap `GetGPUDescriptorHandleForHeapStart` returns 0 for heaps that are not shader-visible; what the console returns for them is not known.
  Title IDs: 1738CA2A
- Device slot 69 takes a 32-bit id and a value and is not identified; it is a probe.
  Title IDs: 1738CA2A
- Device slot 68 fills a structure through its only argument and is not identified; it is a probe and leaves the structure as it was.
  Title IDs: 1738CA2A
- `SetFrameIntervalX` ignores its output and flags; `ScheduleFrameEventX` honours flag 1 (no signal) and ignores the others.
  Title IDs: 1738CA2A
- Graphics command list slots 56 to 59 are taken to be `SetMarker`, `BeginEvent`, `EndEvent` and `ExecuteIndirect` in PC order; no title has called them yet. Slots 60 and up are probes, except 83.
  Title IDs: 1738CA2A
- DMA command list slots 16 to 21 are taken to be `BeginQuery`, `EndQuery`, `ResolveQueryData`, `SetMarker`, `BeginEvent` and `EndEvent`; no title has called them yet. Slots 22 and up are probes.
  Title IDs: 1738CA2A
- `CopyTextureRegionX` (graphics list slot 83) ignores its flags and logs non-zero ones.
  Title IDs: 1738CA2A
- Command list `ResourceBarrier` is taken to return a `UINT`; g6shim returns 0 without knowing what the title reads from it.
  Title IDs: 1738CA2A

  Title IDs: 1738CA2A
- `FlushPipelineX` (graphics list slot 67) is taken to be a cache flush over a memory range and does nothing; its flags are not decoded.
  Title IDs: 1738CA2A

  Title IDs: 1738CA2A

  Title IDs: 1738CA2A

## Functional

- Console-only slots that are not implemented are probes: they log their first four calls and return `E_NOTIMPL`.
- `CheckFeatureSupport` fills the PC part of the 0x40-byte console `D3D12_OPTIONS` structure and zeroes the last 4 bytes.
  Title IDs: 1738CA2A
- Frame events come from a timer that starts at `SetFrameIntervalX`, not from the display's vertical blank.
  Title IDs: 1738CA2A
- Shader-visible sampler heaps of the console's unbounded sampler type (4) become PC sampler heaps of at most 2048 descriptors; `GetDesc` reports the requested size.
  Closes when: a title is seen using more than 2048 samplers, or the heap is split.
  Title IDs: 1738CA2A
- Resources created without `D3D12_RESOURCE_FLAG_ALLOW_DEPTH_STENCIL` lose `D3D12_RESOURCE_FLAG_DENY_SHADER_RESOURCE` on the PC, so shaders could read them where the console would refuse.
  Title IDs: 1738CA2A
- Console DMA command lists are PC copy lists; their console-only operations are probes.
  Title IDs: 1738CA2A
- DMA command list transitions of textures, and transitions of buffers to or from states other than the common and copy states, are dropped; the PC copy queue copies into textures in the common layout, promotes resources from the common state and lets them decay back after each execution.
  Closes when: a title shows a dropped transition that the PC queue does not cover.
  Title IDs: 1738CA2A
- Textures created in a copy state start in the common state on the PC, so copies on any queue promote them. A title barrier that names the copy state as its before state then disagrees with the PC's tracking after a copy queue has let the texture decay.
  Title IDs: 1738CA2A
- Textures answer `GetGPUVirtualAddress` with CPU memory of their own; written pages send the whole texture to the GPU before the next `ExecuteCommandLists`, on the queue that submits. The copy relies on implicit state promotion, is not ordered against other queues, and GPU writes to the texture never reach the CPU memory.
  Closes when: titles are seen reading GPU-written textures through the CPU, or the copy order across queues matters.
  Title IDs: 1738CA2A
- Only single-sample 2D textures of the formats `xg_x` describes get CPU memory. Without the console's XG library they are laid out in tile mode 13, so data a title writes in another layout comes out scrambled; other textures still answer `GetGPUVirtualAddress` with 0.
  Title IDs: 1738CA2A
- Textures are handed to the title as PC objects whose function table is replaced by a copy with its own `Release` and `GetGPUVirtualAddress`.
  Closes when: resources are wrapped in console objects.
- Texture transitions lose the vertex and constant buffer and index buffer states; a transition left with equal states is dropped.
  Title IDs: 1738CA2A
- `PresentX` copies the first resource of the first plane into a flip-model swap chain on the title's largest top-level window and presents without waiting for the display; other planes are ignored.
  Title IDs: 1738CA2A
- Constant buffer views that break the PC's 256-byte alignment read a copy of their data, refreshed from the title's upload buffer before every `ExecuteCommandLists`, so frames still on the GPU may see constants written for a later frame. Views outside upload buffers move down to the alignment and read the wrong bytes.
  Closes when: the copies are tied to the submissions that use them.
  Title IDs: 1738CA2A
