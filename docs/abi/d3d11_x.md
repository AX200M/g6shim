# d3d11_x.dll

Observed layouts. Slot numbers count from 0 and include `IUnknown`.

## Exports

| Export | Signature |
|---|---|
| `D3D11CreateDevice` | PC signature. The SDK version and creation flags differ from the PC's. |
| `D3D11XCreateDeviceX` | `(const parameters*, ID3D11DeviceX**, ID3D11DeviceContextX**)`; the parameter block is 64 bytes |
| `DXGIXPresentArray` | Unknown |

## Immediate context object

| Offset | Content |
|---|---|
| +0x50, +0x58 | Command buffer write pointer and end |
| +0x168 | Dirty bits for the pending state below |
| +0x170 | Primitive topology, packed (see below); written inline by games |
| +0x178 to +0x188 | Pending shaders and input layout, written inline while bit 1 of +0x390 is clear |
| +0x390 | Flags byte. Bit 0: hand each packet to +0xA70. Bit 1: setters call the fast table. |
| +0x3E0 | Fast table: function pointers in context vtable order, called with the context as `this` |
| +0xA70 | Packet function `(context, begin, end)` |

Fast-table entry for context slot *s*: +0x3E0 + 8·*s* for *s* < 24, +0x3E0 + 8·(*s* − 1) for *s* > 24. Slot 24 (`IASetPrimitiveTopology`) is not in the table.

| Offset | Slot | Arguments |
|---|---|---|
| +0x420 | 8 `PSSetShaderResources` | `(views*, start slot, packed)`: one view |
| +0x428 | 9 `PSSetShader` | `(shader)` |
| +0x438 | 11 `VSSetShader` | `(shader)` |
| +0x440 | 12 `DrawIndexed` | `(start index \| index count << 32, base vertex)` |
| +0x468 | 17 `IASetInputLayout` | `(layout)` |
| +0x478 | 19 `IASetIndexBuffer` | `(index size, buffer, offset)`; 0 is 16-bit |
| +0x498 | 23 `GSSetShader` | `(shader)` |

Other entries take the PC arguments of their slot as far as observed.

## Topology value

Indexed by `D3D11_PRIMITIVE_TOPOLOGY`; entry 4 (triangle list) is `0x9FFC0009E00`. In the high dword:

| Bits | Meaning |
|---|---|
| 9-14 | Primitive type: 1 points, 2 lines, 3 line strip, 4 triangles, 5 triangle fan, 6 triangle strip, 9 patches, 10-13 the adjacency kinds |
| 20-25 | Control points, for patches |

Topology indices 14 to 28 are console-only kinds.

## Packets

Each packet is a 4-byte header followed by 16-byte entries.

| Header bits | Meaning |
|---|---|
| 0-7 | Entry count |
| 8-15 | First slot |
| 16-23 | Stage: 0 vertex, 1 hull, 2 domain, 3 geometry, 4 pixel, 5 compute, 6 input assembler |
| 24-31 | Type: `0x80` shader resource view, `0x91` buffer, `0xA0` sampler |

| Entry offset | Content |
|---|---|
| +0 | Object pointer |
| +8 | Value. Buffers: `stride << 48 \| (GPU address − buffer field +0x30)` |

A buffer's GPU address is kept at +0x30 of the buffer object. Constant buffers are bound at any 64-byte offset into memory the game fills itself.

## Resource creation

| Call | Console use |
|---|---|
| `CreateTexture2D` | Dynamic textures without CPU access flags; misc flags `0x20000`, `0x40000`; 2 samples at quality 2, read through single-sampled views |
| `CreatePlacementBuffer` | The `D3D11_BUFFER_DESC` of a dynamic buffer and a zeroed block from the game's GPU heap; default usage may ask for CPU write access |
| Shader resource views | Depth formats such as `D16_UNORM` |
